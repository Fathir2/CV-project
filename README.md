# Single-Page CV (HTML Only)

A simple, clean, and responsive single-page CV website built with only HTML and CSS — no frameworks or JavaScript involved.

📄 Description

This project is a personal CV/Resume presented as a single web page. It’s designed to be lightweight, fast-loading, and easy to customize. Perfect for showcasing your profile, skills, and experience online.
